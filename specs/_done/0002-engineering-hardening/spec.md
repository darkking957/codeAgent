# spec: 工程化加固

状态：已完成

## 背景

#0001 交付了可用的纯对话 TUI，模块切分清晰，但整体偏原型：错误处理薄、持久化非原子、重试不分类、配置不校验、无日志、无自动化测试与工具链。本 spec 在**不改对话核心行为、provider 接口、StreamChunk 协议、TUI 视觉与交互、四个配置字段语义**的前提下，把它加固到工程化质量，并建立可回归的测试与工具链基线。

本 spec 不新增任何对话能力。

## 与 #0001 的关系

- **保契约**：`BaseProvider.stream_chat`、`StreamChunk`（THINKING/TEXT/DONE）、Conversation 消息格式、命令集、TUI 外观，均不变。
- **调整一处行为**（supersedes #0001 的重试语义）：重试改为**按异常类型分类**——不可恢复错误（认证、请求非法等）不再重试、立即失败；只有瞬时错误才退避重试。#0001 checklist 中"无效 key → 3 次重试"的断言由本 spec 重新定义（无效 key → 立即失败；3 次退避由可重试错误触发）。
- **修复一处缺陷**：Anthropic 非思考模式输出上限疑似笔误，纠正为正确值，并连同思考模式上限一起改为可配置（默认值保持纠正后的行为）。

## 目标用户

- 在终端使用 CoreAgent 的开发者（受益于更稳的错误/持久化/重试体验）。
- 维护本项目的开发者（受益于测试与工具链）。

## 能力清单

健壮性：

1. 配置在**加载时即校验**：protocol 取值合法、model 与 api_key 非空（api_key 在 `${ENV}` 解析后判空）、thinking 预算为正；任一不满足，报出**指明字段与期望值的中文错误**并以非零码退出，不向用户抛裸栈。
2. 对话历史**原子写入**：写临时文件后替换，写入过程被中断不损坏既有历史。
3. 历史文件损坏（非法 JSON / 结构非法）时**不崩溃**：备份损坏文件、以空历史启动、记录告警。
4. 重试**按异常类型分类**：仅对瞬时错误（连接 / 超时 / 限流 / 服务端错误）退避重试；不可恢复错误立即失败。
5. 重试**不重复已输出内容**：某次尝试一旦已流出任何 chunk，再发生异常不重试，直接上抛（避免重复刷屏）。
6. 引入**结构化日志**（标准库 logging）：诊断信息（异常详情、重试、损坏恢复）走 logger，级别由环境变量控制，默认安静、不污染对话界面。
7. provider 中的输出上限 magic number 归入配置（带默认值）。

可测试性 / 工具链：

8. 提供 **pytest 测试套件**，覆盖 config / conversation / retry / providers 的核心与边缘路径，**不依赖真实网络与 API key**（provider 用假对象）。
9. 提供 **lint（ruff）/ 类型检查（mypy）/ 测试（pytest）** 配置，命令化一键可跑。
10. 运行时依赖与 dev 依赖分组；运行时仅新增 pydantic（配置校验）。

## 非功能要求

- 对话核心行为、UX、协议、命令、四个配置字段语义不变（除"与 #0001 的关系"列明的两处）。
- 流式首字节延迟不变，不引入额外缓冲。
- 重试对用户可见（界面仍打印"第 N 次重试…"）——但表现层与重试逻辑解耦（回调 + 日志）。
- 测试在无 API key、无网络下全部通过。
- 默认日志级别不打印到对话区；可经环境变量调高用于排障。

## 设计骨架

```
coreagent/
├── errors.py          领域异常（ConfigError 等），供入口分类处理
├── config.py          带校验的配置模型（pydantic）+ ${ENV} 解析 + 上限字段
├── conversation.py    原子写入 + 容错加载（损坏→备份+空历史+告警）
├── retry.py           异常分类 + 重试循环（分类/已输出守卫/on_retry 回调/logging）
├── providers/*        消除 magic number、补类型；接口与产出不变
├── tui.py             传入按现有样式打印"第 N 次重试"的回调；其余不变
└── main.py            配置日志；按领域异常分类干净退出；接通重试提示回调
tests/                 pytest 用例 + 假 provider（无网络）
pyproject.toml         optional-dependencies.dev + ruff/mypy/pytest 配置
```

依赖决策：

- **采用 pydantic** 做配置校验：声明式、报错可定制为中文、契合工程化配置惯例。
- **不引入 tenacity**：流式重试需"已 yield 后不再重试"语义，tenacity 对异步生成器难以表达（要么破坏流式、要么重复输出），手写分类重试更正确也更简单。
- dev 工具：pytest / pytest-asyncio / ruff / mypy。

## Out of Scope

- 不新增对话功能；不引入 tool use / LangGraph / RAG / MCP（后续 spec）。
- 不改 TUI 视觉与交互、不加 Markdown 渲染。
- 不改 OpenAI provider 的输出上限行为（维持当前不设上限）。
- 不做 CI（GitHub Actions 等）；本 spec 只到"本地一键可跑"。
- 不做多会话管理 / 会话切换。
